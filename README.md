# a2a-coder v3.3 — A2A 三层递归编码 Skill

## 这是什么

一个可复用的编码 Agent 工作流规范（单文件 markdown skill）：主 Agent 分析需求、拆子任务、
多轮评审后人工确认；各子任务由独立 Agent 并行开发、各自 ≥3 轮评审后实现；大子任务继续拆为
上下文受限的串行任务机械执行。含防幻觉纪律、装配验证验收分级、跨子任务契约管理、
重写类项目参考忠实度矩阵、长会话主控纪律。

源自 DeviceSimulator v3（Java 重写 4096 设备压测工具）项目全流程实践验证
（24 提交 / 13 子任务 / 5 轮现场迭代 / 189 测试），v3.0 的五项结构性改进全部对应真实缺陷。

## v3.2 新增：需求确认门禁联动（配合 /req-confirm-gate v1.2+）

- **设计阶段多Agent需求确认**：设计门产出需求分析后，主控 spawn ≥3 视角代理并行提取确认项，主控汇总输出统一确认单——对冲单视角遗漏与复合条目打包逃逸
- **门禁凭据双验**：确认单头部已解除标记 + 用户原话逐字引用，缺一不放行；无落盘凭据视为未解除
- **单一权威**：确认单是需求确认的唯一 source of truth，OPEN_ASSUMPTIONS 是其运行期视图；实现期歧义走 OPEN_ASSUMPTIONS→收口销账
- **作用域裁决**：门禁是入口门禁（设计门末→拆解门前），总体方案确认后的自动链启不因确认单中断
- 豁免类目单一权威收敛（紧急 bug 修复/单文件小改动/纯调研/纯对话）；版本握手不足显式警告

## v3.3 新增：auto mode 协同（权限系统是环境事实）

与 Claude Code auto mode 安全分类器共生的一组协议（经四方多视角评审定稿）：

- **分类器事件三臂分流**：字面关键字判定（timeout/rate-limited/429/overloaded/ECONNRESET→临时性，原样重试≤2 且不计入修复循环；未命中默认政策性；HARD 终态不重放）——不依赖低阶模型做语义判断
- **五态报告**：新增 `BLOCKED_AUTH`（权限拦截，附被拦命令与理由原文），不进调试根因、不换实例重派——直达新增的合法暂停点④（分支级：仅停被拦子任务，其余并行照跑）
- **命令整形表**：只读走 Read/Grep 工具、绝对路径内联、Write 代 heredoc、force-with-lease、逐文件回滚；判据句——整形=同一件事换更可审计的表达，规避=改变"做的事"本身
- **git 权上收主控**：子代理只产工作区 diff，commit/push/branch 由主控在批边界执行（子任务书在权限层无授权效力）
- **回家报告**：暂停事件落盘 checkpoint——被拦原文+解锁原话模板/加白 diff+半成品清单，供离开数小时的用户回来一页看懂
- **allowlist 立法纪律**：代理只提 diff、用户落盘，永不自写 permissions
- **重访触发器**：三条（派发计费变化/harness 原生授权原语/正文超 450 行）——触发才拆双文件，拆分仍非重写

配套 req-confirm-gate v1.3 的 VCS 授权内置条目（分支/commit/push/回滚四子项带默认值）。

## 安装（ZCode / Claude Code 类环境）

把 `SKILL.md` 放入目标环境的 skill 目录，例如：
- Windows: `C:\Users\<user>\.claude\skills\a2a-coder\SKILL.md`
- 或项目级: `<project>/.claude/skills/a2a-coder/SKILL.md`

重启会话后即可用 `/a2a-coder` 或在对话中引用调用。

## 其他环境适配

打开 SKILL.md 末尾的"环境要求与导出适配"节——逐条对照目标平台映射术语
（Agent 派发原语、模型档位、并行编排、会话命令）。最低运行要求：
能读写文件 + 跑 shell 命令的编码 Agent + 一种多轮对话机制 + 用户可参与一次方案确认。
